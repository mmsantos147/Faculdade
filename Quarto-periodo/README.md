# Matérias do Quarto Período

---
- **Compiladores**: matéria de Teoria de Linguagens e Compiladores — construção de um compilador para a linguagem "simples" usando Flex e Bison;
- **Estatistica**: matéria de Estatística — scripts em R para amostragem, tabelas de frequência e gráficos;
- **Gestao-de-Ciclo-de-Vida-da-Aplicacao**: matéria sobre o ciclo de vida de aplicações — builds com Maven/Gradle, TDD com JUnit e APIs com Spring Boot.
