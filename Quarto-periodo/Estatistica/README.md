# Estatística

---
Matéria de Estatística aplicada, com práticas feitas em R (e R Commander): técnicas de amostragem, tabelas de distribuição de frequência, medidas resumo e visualização de dados.

## Pastas

- **Scripts**: códigos em R:
  - `aulaamostragem.R` / `sla.r`: aula prática de amostragem — amostragem casual simples sobre a variável idade;
  - `Aula_tabela.R` / `teste.r`: construção de tabela de distribuição de frequência com número de classes calculado (regra da raiz / Sturges) e casas decimais configuráveis;
  - `Questão_1_Tecnicas_de_Amostragem.R`: trabalho sobre técnicas de amostragem aplicadas a dados de renda e situação laboral;
  - `RCommander.R` / `RCommander.txt`: comandos gerados pelo R Commander para medidas resumo (média, desvio padrão, IQR e quantis);
- **Tabelas**: planilhas de dados usadas pelos scripts (`.xlsx` e `.ods`);
- **Graficos**: gráficos gerados nas práticas (barras, boxplot, histograma, pizza e dispersão) em PDF.
