# Códigos feitos a parte da faculdade
---
Códigos desenvolvidos por conta própria durante os primeiros períodos, fora das matérias.

- **Calculadora.c**: calculadora de terminal feita em C com menu de operações — aritmética básica (soma, subtração, multiplicação e divisão), equação de segundo grau (Bhaskara), área e perímetro de quadriláteros e triângulos, e área e comprimento de circunferências. Usa `goto` para controlar o fluxo do menu; uma versão reestruturada em C++ está em `Codigos-refeitos/calculadora.cpp`.
