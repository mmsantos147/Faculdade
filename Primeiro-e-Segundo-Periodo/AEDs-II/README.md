# Matéria de Algoritmos e Estrutura de Dados II
---
O foco da matéria é o estudo de estruturas de dados como:
- Lista sequencial;
- Lista encadeada;
- Fila;
- Pilha;
- Arvore binaria;
- Arvore binaria de Busca;
- Arvore rubro negra;
- Arvore AVL.

## Arquivos

- **aula-lista-encadeada.cpp**: implementação de lista encadeada feita em aula (inserção, busca e remoção de nós com chave e valor);
- **encadeado.cpp**: lista encadeada com estrutura de cabeçalho (`tLista`) que mantém o tamanho da lista, com funções documentadas de inserção e remoção;
- **Revisãoprova.cpp**: revisão para a prova, baseada na implementação de lista encadeada do `encadeado.cpp`;
- **arvore-bin-busca.cpp**: árvore binária de busca com operações de inicialização, busca e inserção;
- **prova2.cpp**: exercício de prova — árvore binária de busca (criação e inserção de valores);
- **prova2.c**: exercício de prova em C — tabela hash de estudantes (nome e matrícula) com tamanho configurável;
- **projetocarro.cpp**: projeto prático da matéria — sistema de cadastro de veículos de uma concessionária, com inserção, busca, remoção e persistência dos registros em arquivo;
- **DB_Veiculos / bdbackup.txt**: base de dados de veículos usada pelo `projetocarro.cpp` (e seu backup).
