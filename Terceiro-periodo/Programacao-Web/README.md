# Programação Web

---
Matéria sobre desenvolvimento web: estrutura de páginas com HTML, estilização com CSS, interatividade com JavaScript e publicação em servidor Apache.

- **Aulas**: sites e exercícios desenvolvidos em aula (Aulas 7 a 16 — básico de HTML/CSS/JS, manipulação de elementos, menus de navegação e tarefas de estilização);
- **Outros-Codigos**: projeto particular feito a parte da faculdade — o `Site-teste`, um site com templates HTML, estilos CSS, scripts JavaScript e sistema de registro/login em Python usando Flask e banco SQLite.
