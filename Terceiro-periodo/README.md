# Matérias do Terceiro Período

---
- **Orientacao-a-Objetos**: matéria de Programação Orientada a Objetos em Java (classes, encapsulamento, herança, polimorfismo, exceções e projetos práticos);
- **Programacao-Funcional**: matéria de Programação Funcional em Haskell (funções, guardas, tipos, tuplas e listas);
- **Programacao-Logica**: matéria de Programação Lógica em Prolog (fatos, regras, recursão, listas e resolução de problemas);
- **Programacao-Web**: matéria de Programação Web (HTML, CSS, JavaScript e um site de teste com Flask).
