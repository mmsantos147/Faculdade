# Programação Funcional

---
Matéria sobre o paradigma de programação funcional usando Haskell: funções puras, guardas, casamento de padrões, tipos e sinônimos de tipos, tuplas, listas e recursão.

## Arquivos

- **Lista1.hs**: resolução da lista de exercícios 1 — definição de funções com guardas e condicionais (funções aritméticas por casos, comparações entre parâmetros);
- **prova.hs**: estudo para a primeira prova — uso de sinônimos de tipo (`type`) e tuplas para modelar brindes de viagem (cidade, passagens e hospedagens), com funções de consulta sobre esses dados.
