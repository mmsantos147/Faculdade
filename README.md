# Projetos e códigos feitos durante a Faculdade

Repositório com os códigos desenvolvidos ao longo do curso de Ciência da Computação (UNIFAL-MG), organizados por período.

## Estrutura

- **Primeiro-e-Segundo-Periodo**: Algoritmos e Estruturas de Dados II e códigos avulsos em C/C++;
- **Terceiro-periodo**: Orientação a Objetos (Java), Programação Funcional (Haskell), Programação Lógica (Prolog) e Programação Web (HTML/CSS/JS/Flask);
- **Quarto-periodo**: Compiladores (Flex/Bison), Estatística (R) e Gestão de Ciclo de Vida da Aplicação (Java/Spring/TDD);
- **Quinto-periodo**: Processamento de Imagens (C, Java e Python);
- **Codigos-refeitos**: versões reescritas e melhoradas de códigos antigos do repositório.
